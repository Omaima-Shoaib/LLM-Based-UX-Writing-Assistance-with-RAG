# RAG-Based UX Microcopy Generation and Evaluation

This repository accompanies the paper "LLM-Based UX Writing Assistance with RAG". It contains the knowledge base, UX writing tasks, generated responses, and evaluation results used to compare a RAG-enabled configuration with the same base LLM without retrieval.

The knowledge base is built from the Google UX Writing Guidelines and the Visa Secure Guidelines.

## Implementation

The RAG implementation follows the tutorial Make your own RAG by Xuan-Son Nguyen (ngxson) https://huggingface.co/blog/ngxson/make-your-own-rag. Only the knowledge base and the input instructions were changed for this study.
